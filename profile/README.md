# pheasaKhmer

Open tools for the Khmer language (ភាសាខ្មែរ). They work offline where they can, document
where their data comes from, and are checked by native speakers.

| Project | What it does |
|---|---|
| [pheasa](https://github.com/pheasaKhmer/pheasa) | Normalizer for Khmer text, so text that looks the same is the same, and a benchmark for Khmer language AI |
| [khmer-engine](https://github.com/pheasaKhmer/khmer-engine) | Converts chat-style romanized Khmer to Khmer script (`sok sabay te` → សុខសប្បាយទេ) and back |
| [khmer-keyboard](https://github.com/pheasaKhmer/khmer-keyboard) | Android keyboard on a Rust core: type Khmer in Latin letters, or on a Khmer layout; nothing leaves the phone |
| [khmer-converter](https://github.com/pheasaKhmer/khmer-converter) | Web page and Telegram bot for the same conversions |

Found a wrong conversion? Open an issue in the project you used, with what you typed,
what you got and what you expected.
