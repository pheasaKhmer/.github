# Contributing

Thank you for helping. Each repository's README explains how to build it and run its
checks; this is what applies to all of them.

- **Spellings and conversions.** Reports of wrong Khmer are the most useful contribution.
  Use the "Wrong conversion" issue form: what you typed, what you got, what you expected.
- **Larger changes.** Open an issue first, so the approach can be agreed before you write
  the code.
- **Pull requests.** One concern per pull request, with commits in the
  [Conventional Commits](https://www.conventionalcommits.org/) style
  (`fix(core): ...`). The repository's check command (`make check`) must pass, and the
  description says what changed, why, and how it was tested.
- **Data.** Only data whose license allows redistribution, with its source recorded.
  Khmer in tests and data files is marked as reviewed only once a native speaker has
  checked it.
